# Thiago Castilho — Personal desktop

Personal website covering software architecture, applied AI, teaching, games, study, and life outside work.

**Website:** https://tvcastilho.github.io/

Static HTML/CSS and a small JavaScript layer; no build dependencies. Pages publishes only `site/`.

## Local preview

```sh
python3 -m http.server 4173 --directory site
python3 tools/check_site.py
```

The teaching and Castle presentation illustrations are AI-generated concepts. The game showcase uses Games4Fun game logos. Demo outputs are labeled separately and credit TensorFlow.js examples. Private project source and unpublished review materials are excluded.
